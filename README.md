You need Python installed from python.org (or the micosoft store at https://apps.microsoft.com/detail/9nq7512cxl7t?ocid=webpdpshare), with “Add Python to PATH” enabled.
This py script will:
Download Discord, Firefox, VS Code, Medal, and Vencord (vencord is discord homebrew).
Install Discord, Firefox, VS Code, and Medal.
Leave Vencord uninstalled until you click the popup button.
Schedule a Windows restart after the process completes
